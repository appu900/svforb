Saveful for Business API

202 endpoints across 29 areas. 177 require a bearer token, 25 are public. Every path below is prefixed /api/v1.

Authenticate — call POST /auth/login, then send the token on every other request:

Authorization: Bearer <token>

Enterprise endpoints also require the organisation to be on the Enterprise plan and check the caller’s role and scope. A 403 carrying MISSING_PERMISSION means the role is wrong; OUTSIDE_SCOPE means the role is right but the target is outside what the caller can reach.
